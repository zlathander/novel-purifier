# 记忆系统总纲 (MEMORY_ARCHITECTURE)

## 1. 记忆架构概述
本记忆架构是【网络小说出版级文本清洗与自演进修复 Agent】的知识底座与演化中心。负责在无人工值守（Fire-and-Forget）模式下，提供高置信度的确定性清洗规则、上下文语义修复案例库，并动态记录新发现的文本异常类型。

## 2. 当前已积累检测维度 (Taxonomy Dimensions)
1. **盗版广告与站点水印**：小说头尾采集站站点信息、章节内夹杂的防盗域名（如 `101kan.com`、`101??????.??????`、全手打无错站等）。
2. **HTML实体转义残留**：如 `&#183;` (·)、`&#215;` (×)、`&#247;` (÷)、`&#176;` (°)、`&gt;` (>)、`&amp;` (&)、`&quot;` (")、`&#39;` (') 等。
3. **编码错位与繁简残留**：转码过程中的典型错字（如 `什幺/那幺/怎幺` -> `什么/那么/怎么`、`擡` -> `抬`、繁体技术术语残留如 `人工智慧` -> `人工智能`、`晶片` -> `芯片`、`列印` -> `打印`）。
4. **机械叠词与标点重复**：采集或转码产生的非拟声机械重复标点（如 `。。` -> `。`）。
5. **章节标题污染与重复**：
   - 章节标题中的求票、加更、追读后缀（如 `（求追读）`、`（求月票）`、`（求首订）`、`（30000收藏加更）`、`（为盟主冰美式加更110）` 等）。
   - 采集站由于页面 HTML 抓取结构产生的章节标题连续重复行（如相邻两行均为相同章节名，或首行为爬虫抓取网页头，次行为带缩进的正文真实章节名）。
6. **独立请假条/单章剥离**：夹杂在正文中的作者请假条、上架感言、卡文通知，完整剥离存档至 `reports/author_notes.txt`，保持小说主干文本纯净。
7. **专有名词与人名漂移**：
   - 人名笔误/漂移（如 `雷格亚兹` -> `雷迪亚兹`、`西恩斯` -> `希恩斯`）。
   - 专有名词及外文缩写规范化（如 `pdc` / `pcd` -> `PDC`、`bbc` -> `BBC`、`eto` -> `ETO`）。
8. **OCR形似字与同音错字**：
   - 常见形似字：`战土` -> `战士`、`未日` -> `末日`、`士/土`、`拔/拨`、`己/已/巳`、`念叻` -> `念叨`。
   - 同音词漂移：`时间的退役` -> `时间的推移`。
   - 局部重度 OCR 损坏段落（如第452章太空战章节中字形误读）：`业队` -> `舰队`、`战业` -> `战舰`、`行回亜` -> `行星级`、`恒回亜` -> `恒星级`、`电磁违道炮` -> `电磁轨道炮`、`成亍` -> `成功`、`狐来` -> `看来`、`都狐到` -> `都看到`、`来狐` -> `来看`、`散的很竖` -> `散的很开`、`伸均战业` -> `平均战舰`、`面壁仂` -> `面壁者`、`猴6` -> `猴子`、`三到了` -> `回到了`、`久知道` -> `不知道`、`绝久可能` -> `绝不可能`、`久算` -> `不算`、`罗辑博[，？]` -> `罗辑博士`、`不知世` -> `不知晓`、`刃许` -> `或许`、`丫一步` -> `下一步`、`赶过来仂` -> `赶过来了`、`毫飞魄散` -> `魂飞魄散`、`属开亿兆计` -> `数以亿兆计`、`亥码` -> `数码`、`四维空间碎研究` -> `四维空间碎片研究`。
9. **敏感词屏蔽与拼音缩写**：
   - 平台敏感词替换/缩写导致的语病修复（如 `撒gg` -> `撒广告`）。
10. **标点与引号配对异常**：
    - 同向引号：`「...「` 修正为 `「...」`。
    - 末尾反向引号：对话行末以 `「` 结尾的误打，修正为 `」`。
    - 叙述句中单边后引号前缺失前引号（如 `这个名为人类」` -> `这个名为「人类」` 等）。
    - 嵌套引号混淆：如 `『被联合政府压榨歧视」` -> `『被联合政府压榨歧视』`。
11. **悬空注释与软件残留**：
    - 缺少注释内容的悬空标记（如正文出现的 `［注1］`）。
    - 爬虫网站独立分页跳转遗留符（如独立一行的 `>` 或 `&gt;`）。
12. **段落排版与硬回车断行**：
    - 对话粘连、断行及空行规范化。

## 3. 防误伤红线 (Negative Constraints)
1. **严禁篡改作者文风**：
   - 严禁对作者口语化表达、网文热梗（如 `.jpg`、特定网络拟声词、抽象话、表情符号）进行“文学润色”或“语法改写”。
   - 严禁删除正文中角色正常对话、独白或剧情讨论中提及的敏感词或网站名（例如角色台词吐槽提到 `笔趣阁`、科学讨论中提到的四维空间 `顶点` 等，严禁当作广告删除）。
2. **置信度分级裁决**：
   - 置信度 ≥ 90%：自动化脚本或补丁精准替换。
   - 置信度 < 90%：保持原文不动，记录至 `reports/uncertain_review.log`，绝不因犹豫中断流水线。
