# 记忆系统总纲 (MEMORY_ARCHITECTURE)

## 1. 记忆架构概述
本记忆架构是【网络小说出版级文本清洗与自演进修复 Agent】的知识底座与演化中心。负责在全自动无人值守（Non-Interactive & Auto-Approve）模式下，提供高置信度的确定性清洗规则、上下文语义修复案例库，并动态记录新发现的文本异常类型。

## 2. 当前已积累检测维度 (Taxonomy Dimensions)
1. **盗版广告与域名水印**：小说头尾采集站站点信息、章节内夹杂的防盗域名（如 `101kan.com`、`101??????.??????`、全手打无错站、更新不易记得分享网、记住我们网、最⊥新⊥小⊥说⊥在首发等）。
2. **HTML字符实体**：如 `&#183;` (·)、`&#215;` (×)、`&#247;` (÷)、`&#176;` (°)、`&gt;` (>)、`&amp;` (&)、`&quot;` (")、`&#39;` (') 等。
3. **编码错位与繁简残留**：如 `什幺/那幺/怎幺/这幺/多幺/要幺` -> `什么/那么/怎么/这么/多么/要么`，`擡` -> `抬`，`凭藉` -> `凭借`，繁体计算机术语如 `人工智慧` -> `人工智能`、`晶片` -> `芯片`、`列印` -> `打印`。
4. **重复章节标题与非正文杂项**：
   - 爬虫抓取网页头导致的连续重复章节标题行。
   - 章节标题尾部的 `（求追读）`、`（求月票）`、`（求首订）`、`（加更）` 等求票后缀。
   - 正文夹杂的独立请假条、上架感言、卡文通知（独立剥离归档至 `reports/author_notes.txt`）。
5. **机械叠词与标点重复**：非拟声机械重复标点（如 `。。` -> `。`）及语言模型/采集卡顿产生的叠词（如“的的”、“生命的的”、“在在”）。
6. **OCR形似字集群**：如 `士/土`（战土/博土/修土 -> 战士/博士/修士）、`未/末`（未日->末日）、`看/狐`（狐来->看来、都狐到->都看到）、`舰/业/航`（业队/战航->舰队/战舰）、`念叻` -> `念叨`、`成亍` -> `成功` 等。
7. **同音错别字**：根据上下文推断的同音错字，如 `时间的退役` -> `时间的推移`、`无畏的挣扎` -> `无谓的挣扎`。
8. **专有名词拼写漂移**：人名笔误（`雷格亚兹` -> `雷迪亚兹`、`西恩斯` -> `希恩斯`、`东方延续` -> `东方延绪`）及机构英文缩写（`pcd/pdc` -> `PDC`、`bbc` -> `BBC`、`eto/et0/teo` -> `ETO`、`m0ss/moos` -> `MOSS`）。
9. **敏感词和谐残缺句**：平台屏蔽字词缩写或拼音残留（如 `撒gg` -> `撒广告`、`贴纸gg` -> `贴纸广告`、`gg牌` -> `广告牌`）。
10. **标点与引号配对异常**：
    - 末尾反向引号（`...「` -> `...」`）。
    - 行内反向引号（`「...「` -> `「...」`）。
    - 叙述文本中单边后引号前缺失前引号（如 `这个名为人类」` -> `这个名为「人类」`）。
    - 嵌套括号引号混淆（如 `『...」` -> `『...』`）。
11. **悬空注释与分页符残留**：
    - 正文中缺少对应注释内容的孤立标记（如 `［注1］`、正文孤立行数字）。
    - 爬虫独立网页分页遗留符（如孤立的 `>` 或 `&gt;`）。
12. **防盗乱码与异书填充**：防盗混淆段落与异书无关正文插入识别。
13. **段落排版与断行粘连**：对话粘连同行、非段末跨空行断裂。
14. **防盗字符别名置换混淆**（新注册）：盗版站系统性反向加密替换，如“八体->三体”、“七维->四维”、“白暗->黑暗”、“散冷->散热”等。
15. **核物理与同位素字形损坏**（新注册）：如恒星聚变语境下“氘和氚”偏旁脱落损坏为“气和氙 / 气和”，“氦闪”识别为“氮闪 / 氨闪”。
16. **连载作者碎碎念与催更提示**（新注册）：正文末尾夹杂作者连载更新提醒、请假碎碎念。
17. **科学计数法指数截断丢失**（新注册）：如 `7.1×101焦耳` 修复还原为 `7.1×10^19焦耳`。
18. **科学计数法上标脱落还原（SCI_NOTATION_RECOVERY - 仲裁五大铁证之一）**：针对微观粒子数量、天体质量、天体辐射功率、极端能级（如施温格极限、质子衰变时间、恒星总数）因纯文本降维丢失指数上标的系统性错误，严格基于物理定律与计算上下文还原标准科学计数法表示（如 `7×102` -> `7×10^23`、`6.67×10千克` -> `5.97×10^24千克`、`3.828×10瓦` -> `3.828×10^26瓦`、`102以上` -> `10^20以上`、`10+焦耳` -> `10^43焦耳`）。
19. **正文内嵌分割线/括号式作者日常随笔剥离（INLINE_AUTHOR_DIARY_STRIP - 仲裁五大铁证之二）**：针对章节正文中内嵌作者自驾游路况汇报、吃饭打卡、请假碎碎念等“作者有话说”杂项，彻底从正文剥离并归档至 `reports/author_notes.txt`，恢复纯净出版阅读沉浸感。
20. **草稿相邻重段去重（DRAFT_DEDUP - 仲裁五大铁证之三）**：针对作者起草时连续书写两版同义句子或段落的遗留残稿，保留叙事详尽、定稿成熟的单段，消除机械性语义镜像重段。
21. **紧邻上下文事实与算术自洽裁决（CONTEXT_LOGIC_OVERRIDE - 仲裁五大铁证之四）**：当局部文字与前文死板硬情节产生矛盾（如把罗辑写成罗清、把北美舰队写成亚洲舰队、把侵略地球写成侵略三体）或出现算术矛盾（如“600对也就是120颗”），坚决以全局事实与数学等式为真值源实施覆盖裁决，不留低置信度存疑。
22. **物理单位与外文字母OCR退化修复（UNIT_OCR_RECOVERY - 仲裁五大铁证之五）**：针对微米(μm)退化为皮米(pm)、有机化学分子式花括号乱码、苏联武器西里尔字母退化为英文字母（如 Н-37 退化为 h-37）、角秒符号退化为方括号等，严格依据行业命名规范修复。

## 3. 防误伤红线与仲裁二审协议 (Negative Constraints & Arbitration)
1. **严禁篡改作者文风**：
   - 严禁对作者正常的口语化表达、网文热梗（如 `.jpg`、［大拇指］、日/昌/晶、拟声词、网络用语、仗育、人格侮乳）进行文学润色或语法重写。
   - 严禁删除正文中角色正常台词、剧情讨论中出现的网站名称（如吐槽“笔趣阁”等）。
2. **两级裁决架构与二审协议（Step 3.5: scripts/04b_arbitrate_uncertain.py）**：
   - **蜂群初审**：Sub-Agent 仅读取单批次 12 章局部文本，保持高度克制，凡局部无法绝对断定者列入 `uncertain_items`。
   - **首席仲裁官二审（Step 3.5 强制执行）**：主 Agent 在导出最终成品前，对汇总的所有 `uncertain_items` 实施全局复核：
     1. **全书词频悬殊检索（Global Corpus Frequency Verification）**：
        统计疑似错词 $W_{wrong}$ 与推测正词 $W_{right}$ 在全书的词频分布。若 $\text{count}(W_{right}) \ge 5$ 且 $\text{count}(W_{wrong}) \le 2$，且上下文无刻意玩梗说明，直接由存疑升格为 **高置信度修复（Confidence = 0.98）**！
     2. **五大必改判据（果断修复，不留存疑）**：
        - **主谓宾语义冲突的同音词**：如字面虽为合法词但与主语在物理/常识上完全不通（如“时间的退役”必为“时间的推移”），直接修复。
        - **现代汉语零搭配率的形似字**：如两个单字组合在正常汉语中完全不通，而替换一个笔画相近字（如 `看/狐`、`士/土`、`未/末`、`舰/业`、`坚/开`）即恢复为高频常用词，直接修复。
        - **局部漏字/多字导致的明显语病**：在不改变作者句子结构的前提下，补全因 OCR 或转码吞掉的单一虚词/助词或删除机械多字，直接修复。
        - **科学计数法上标脱落与物理单位退化**：严格依据物理定律、算术常识与国际标准还原（如 `7×102` -> `7×10^23`、`6.67×10千克` -> `5.97×10^24千克`、`0.5pm` -> `0.5μm`）。
        - **正文内嵌作者随笔剥离与草稿相邻去重**：章节内嵌的作者自驾游路况、请假随笔剥离至 `reports/author_notes.txt`，连续书写两版同义草稿去重。
     3. **执行二审替换与经验沉淀**：
        将二审确认的所有条目直接应用至 `work/working_novel.txt`，仅将极少数真正的“作者玩梗/修辞特色”移入白名单展示，真实敏感掩码（如 `***`、`李a华`）留存 `reports/uncertain_review.log`，并将典型转正案例沉淀至 `memory/contextual_cases.json`，赋能后续小说清洗任务。
